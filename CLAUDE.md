# Instruções do repositório

## Regra obrigatória: novo projeto
Antes de iniciar qualquer novo projeto (estudo de viabilidade, vídeo de lançamento, apresentação 3D), replique a estrutura padrão:

```bash
./_modelos/novo-projeto.sh <nome-do-projeto>
```

Depois preencha `<nome-do-projeto>/BRIEFING.md` e siga o fluxo de `_modelos/video-lancamento/README.md`. Não comece arquivos soltos fora dessa estrutura.

Quando um projeto trouxer melhoria reutilizável (script, cena, cálculo), leve a melhoria também para `_modelos/video-lancamento/`.

## Estilo dos textos
- Português do Brasil, direto e orientado à decisão.
- Nunca usar o travessão "—".
